# Hotel Sync — Guest Flow

Internal hotel management system: room grid, bookings, guest registration, shift tracking, and admin/superuser tools.

## Stack

- TanStack Start (React, SSR)
- TypeScript
- Tailwind CSS
- Supabase (database, auth, storage)
- Deployed on Vercel

## Development

\`\`\`sh
npm install
npm run dev
\`\`\`

Copy `.env.example` to `.env.local` and fill in your own Supabase project values before running.
